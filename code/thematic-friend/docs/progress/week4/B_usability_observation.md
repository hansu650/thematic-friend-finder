## Ready-to-use session plan

Use fictional accounts and a fresh local demo following the project runbook. Explain that participation is voluntary, they may stop, and only anonymous task notes will be retained. Request consent before recording notes; do not collect names, contact details or private messages. Do not record audio/video by default.

| Task | Neutral prompt | Record during the actual session |
|---|---|---|
| Profile | Update your fictional profile with interests that suit it. | Whether Save is discovered; sixth-interest understanding; completion without help. |
| Discovery | Find someone you might like to meet. | Navigation, understanding of interest/goal filters and mutual choice; any confusion. |
| Event | Find an activity and save it for later. | Save versus RSVP understanding, confirmed state, ability to find it again. |
| Conversation | Find an existing conversation and send a fictional greeting. | Inbox scanning, preview readability, composer access and confirmed send state. |

Avoid coaching. If help is requested, record the point of difficulty before intervening. Note what happened and any exact voluntary remark, then separate interpretation from observation. Leave time unmeasured unless a timer was actually used.
