# Sources, Dependencies and Assistance

## Current four-site reference revision

At the user's request, the current public navigation follows Bumble, the video hero follows Feeld, the serif editorial section follows Hinge, and the internal cards/detail layout follows the supplied Meetup event. The actual sites were inspected on 13 November 2026. Templates and JavaScript are implemented in this project's Java/Thymeleaf codebase; the reference sites' private source and backend were not copied.

Reference photos, video, branded calendar/location icons and font binaries are served locally under `static/images/reference-sites/` and `static/fonts/reference/`. Exact asset URLs, source sites and filenames are recorded in [the source manifest](../src/main/resources/static/images/reference-sites/sources.json). Fonts include Neu Sans, Bumble Sans, Tiempos Headline, Modern Era, Feeld Edge and Diatype. These assets remain owned by the respective sources; this local comparison does not assert a redistribution licence or endorsement. Reference brand names/logos have not replaced Mingle's identity.

`reference-ui.css` is the active stylesheet. Earlier Comic Neue, Planet, Momo and Preline style layers are retained as historical project files and are not loaded by the current templates. The existing SVG icons/stickers and stock-profile mappings remain where the application needs those functions. The sections below record the provenance of the earlier iterations as well as retained assets.


The project was created by the user in IntelliJ IDEA using Spring Initializr-style Maven scaffolding. The current business logic, templates and interaction scripts were produced with Codex assistance for this course prototype. The team should understand and review this code and follow its course's attribution rules.

No Alovoa source files have been copied. [Alovoa](https://github.com/Alovoa/alovoa) was inspected as a reference option and was not adopted as the codebase. The older local Django prototype and the user's existing full-stack coursework informed flow and visual direction; this Java project is a separate implementation.

Runtime dependencies are declared in `pom.xml`. They include Spring Boot/Spring Framework/Spring Security, Thymeleaf and its security integration, Hibernate ORM, Jakarta validation and H2. Their code remains external dependency code, subject to the licences distributed with each dependency. This note does not relicense those libraries or declare a new licence for the whole project.

Primary implementation references: [Spring web content guide](https://spring.io/guides/gs/serving-web-content/), [Spring Boot SQL data documentation](https://docs.spring.io/spring-boot/reference/data/sql.html), [Spring MVC locale documentation](https://docs.spring.io/spring-framework/reference/web/webmvc/mvc-servlet/localeresolver.html) and [Thymeleaf documentation](https://www.thymeleaf.org/doc/tutorials/3.1/usingthymeleaf.html).

The card interaction uses local JavaScript and CSS. No remote fonts, browser CDN or third-party animation runtime is required. Development screenshots were captured with the user's installed Playwright screenshot helper; that helper is not part of the application runtime.

The planet page takes visual direction from the user's `momo/6.jpg`, `9.jpg` and `5.jpg`. Its canvas star field, orbit lines, gradient cards and native profile dialogs are original HTML/CSS/JavaScript implementations. `static/images/mingle-stickers.svg` is an original six-expression cloud character pack, created in SVG for this project; it contains no third-party artwork, fonts or external references. Regular emoji render with the device's emoji font. The optional sample conversations are explicitly fictional fixtures; live conversation replies come from actual signed-in browser sessions.

The user's full-stack web coursework informed reduced-motion preferences, default-off short Web Audio feedback and restrained entry/press transitions. The Mingle implementation uses native browser APIs rather than copying the Vue components, adding a motion library or loading remote audio. No reference project files were modified.

The free [Preline UI](https://github.com/htmlstreamofficial/preline) 5.1.0 components are adapted in `scripts/ui-build/preline.css` and the templates: [Cards](https://preline.co/docs/components/card.html), [Buttons](https://preline.co/docs/components/buttons.html), [Input](https://preline.co/docs/components/input.html) and [Chat Bubbles](https://preline.co/docs/components/chat-bubbles.html). Their colours, layout, copy and server bindings are specific to Mingle. Both the MIT and Preline UI Fair Use notices are retained verbatim in [Preline-LICENSE.txt](./licenses/Preline-LICENSE.txt). No Preline Pro or paid Social template source has been used. Social was an earlier visual reference; the user's later screenshot direction supersedes its layout.

Tailwind CSS / CLI 4.3.5 compiles the component styles to the local `static/css/preline.css`. The MIT notice is retained in [Tailwind-LICENSE.txt](./licenses/Tailwind-LICENSE.txt). Versions and transitive dependencies are pinned in `scripts/ui-build/package-lock.json`; the application itself continues to run from Spring Boot. [Style build instructions](../scripts/ui-build/README.md).
