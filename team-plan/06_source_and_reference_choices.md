# Source and Reference Choices

The selected implementation is the user-created Spring Boot project at `code/thematic-friend/`, with Thymeleaf templates and JavaScript card gestures in the same application. IntelliJ IDEA edits and runs the project; a browser displays it.

[Alovoa](https://github.com/Alovoa/alovoa) was evaluated as a Java reference. Its backend is Spring Boot, while the complete client uses a separate Expo application. On 6 November the user chose to continue the lightweight single-project website when this distinction became clear. No Alovoa source files have been copied into the Java baseline. Do not describe the baseline as an Alovoa fork or reuse its implementation claims.

The older local Django prototype and the user's full-stack course project informed flow and visual direction. The Java services, templates and scripts were created with Codex assistance and require team review and understanding. Card drag, return and exit animations are implemented in the current website.

Keep exact references and licences for any third-party code added later in the application's [third-party record](../code/thematic-friend/docs/THIRD_PARTY.md). Source inspiration, copied code and independently implemented behaviour must be distinguished.
