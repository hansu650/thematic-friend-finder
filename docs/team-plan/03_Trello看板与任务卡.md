# Trello 看板与任务卡

## 两层管理

Product Backlog 保存整个项目未来可能做的工作，初稿见 [待办列表](./04_Product_Backlog.md)。每个 Sprint 计划会上，再选出本轮能完成的项目进入看板。准备周的调研任务使用 W1 标签单独识别。

建议看板名称为 `Thematic Project 2026 五人协作`，可见性设为私有。由组长确认后创建并添加实际成员，不复用软件开发流程 Lab 的案例看板。

## 五个流程列

| 列名 | 进入条件 | 离开条件 |
|---|---|---|
| Ready to Start 准备开始 | 已选入当前周期；负责人、验收和依赖清楚 | 负责人有容量并实际开始 |
| In Progress 进行中 | 正在调研、设计、编码或整理 | 交付物和自查结果可供复核 |
| Review 交叉复核 | 复核人能打开材料或查看修改 | 意见已处理，进入实际检查 |
| Testing 验证 | 按任务类型进行测试、检查来源或验收 | 达到完成标准，有验证记录 |
| Done 完成 | 复核和验证通过，证据链接齐全 | 有新增问题时开新卡，保留原记录 |

研究和文档卡的 Testing 是“核对来源、结论与可用性”；代码卡则运行相应测试和实际操作。尚未创建的卡片和待讨论的想法留在 Product Backlog。

## 在制工作量限制

初始建议：In Progress 最多 5 张，且每人最多负责 1 张；Review 最多 2 张；Testing 最多 2 张。人数和实际吞吐变化后再调整。这些是本组拟定的起始值，不是课件规定的固定数字。

当复核或测试列达到上限，先帮助完成已有任务。卡片被阻塞时留在所在列，添加红色 `Blocked` 标签，记录原因、处理人、下一次检查时间；阻塞卡仍计入所在列上限。初期由 E 人工检查列中数量，不依赖自动化或付费插件。

## 卡片要写什么

标题格式：`W1-01 A 发现与筛选参考调研`。开发阶段也附关联故事，例如 `W2-01 A US02 筛选与推荐理由改进`。

每张卡写明：目标、负责人、复核人、周期、内部截止时间、交付物、验收清单、前置依赖、估算、证据链接及阻塞。正文用 [任务卡模板](./模板/周任务与任务卡模板.md) 的单卡部分，保持短段落和列表。

使用卡片级 Members 指定主负责人；复核人写在描述中，必要时也加入卡片。标签可用 `Research`、`UI`、`Backend`、`Testing`、`Evidence` 和 `Blocked`，周期使用 W1、S1、S2。无需把每个字段都做成 Custom Fields。

Trello 支持卡片成员、日期、标签、附件和 Markdown 的大部分语法。完整 Markdown 表格不作为卡片显示的前提；把一行任务拆成一张卡，再粘贴单卡正文。支持依据见 [成员设置](https://support.atlassian.com/trello/docs/adding-a-member-to-a-card/) 和 [文字格式](https://support.atlassian.com/trello/docs/how-to-format-your-text-in-trello/)。

## W1 建卡清单

先创建以下五张个人卡，内容分别取自 [A–E 独立任务](./每周任务/W1_个人任务/)，再按 A、E 任务中的特色工作创建两张协调卡。暂不将 W2–W5 的所有预案搬进进行中的看板。

```text
W1-01 A 发现与筛选参考调研
W1-02 B 交互与导航参考调研
W1-03 C 注册与资料参考调研
W1-04 D 匹配与聊天参考调研
W1-05 E 屏蔽举报参考调研
W1-06 E 看板规则与角色确认
W1-07 A 参考取舍与下轮目标
```

W1-06、W1-07 的估算计入 E 和 A 的容量；个人调研完成后再拉取协调卡，避免同时开多个主任务。

## 团队怎么更新

- 开始工作时移动卡片，不在周末一次性把全组卡片移到 Done。
- 交付时贴文件或提交链接，写明完成了什么、还缺什么。
- 复核人留下具体检查结果；需要修改时写清问题，退回进行中。
- 每次讨论形成的新行动都写上负责人、期限和对应卡片。
- Sprint 结束保存看板截图及完成、结转、阻塞的任务清单。截图是真实状态记录，不摆拍已完成成果。

Checklist 可承载验收项；把任务负责人和期限放在卡片层级，方案不依赖高级 Checklist 的逐项指派能力。参见 [Trello Checklist 文档](https://support.atlassian.com/trello/docs/adding-checklists-to-cards/)。
