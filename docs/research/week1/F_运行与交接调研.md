## 核心技术栈职责分工

参考 Spring 官方指南 [S1] 与数据库配置 [S2]，本项目轻量运行职责划分如下：

- **Java 21 (LTS)**：基础运行时环境，提供长期稳定性与现代语言特性，作为 Spring Boot 3.x 的运行底座。
- **Maven Wrapper (`mvnw`)**：构建一致性工具。封装统一版本 Maven，组员无需在宿主机额外配置构建工具，避免环境版本差异。
- **Thymeleaf**：服务端页面模板引擎。负责动态渲染 HTML；支持自然模板特性，未启服务时也可直接在浏览器静态双击预览原型。
- **H2 文件模式**：轻量嵌入式数据库（配置如 `jdbc:h2:file:./data/demo`）。不同于内存模式，它将数据持久化写入本地磁盘文件，重启不丢失数据，且无需安装独立数据库服务。

## IDEA 启动与 `java -jar` 启动比较

- **IDEA 直接启动**：基于 IDE 增量编译与本地依赖缓存，支持断点调试、代码热更与即时生效；但依赖 IDE 内部配置与本地环境，适合日常敏捷开发调试。
- **打包 `java -jar` 启动**：经 `mvn clean package` 产出单一内嵌 Tomcat 的 Fat Jar。完全脱离 IDE，以生产标准运行，具备高度确定性与环境独立性，适合团队交接、CI/CD 与演示运行基准。

## 启动前提与数据目录建议

- **启动前提**：已安装 JDK 21+（`java -version` 确认）；macOS/Linux 执行 `chmod +x ./mvnw` 赋予权限；默认 8080 端口未被占用。
- **数据目录建议**：H2 文件建议配置为工程根目录相对路径 `./data/friendfinder`。**必须在 `.gitignore` 中加入 `/data/` 及 `*.mv.db`**，严禁将个人运行生成的本地数据库二进制文件提交到 Git，防止合并冲突与数据污染。

## 重启验证步骤与实测状态

**数据持久化验证步骤**：
1. 终端启动服务（`./mvnw spring-boot:run` 或 `java -jar target/*.jar`）。
2. 在浏览器录入一条测试数据（如新建个人资料）。
3. 确认 `./data/` 目录下生成 `friendfinder.mv.db` 文件。
4. 使用 `Ctrl + C` 正常终止服务进程。
5. 重新启动服务并刷新页面，验证先前录入的数据仍然存在。

**实测状态**：
- **已实际验证**：Java 21 下 Maven Wrapper 调度、`java -jar` 独立启动，以及 H2 文件模式在进程终止后生成 `.mv.db` 并保留数据的机制已在本地实测通过。
- **待验证**：本系统专属的实体表结构、真实种子数据初始化脚本与自动迁移策略，待 W2 任务接入业务代码后验证。
