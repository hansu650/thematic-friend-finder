# 过程证据与个人反思模板

本文件提供后续填写方式。空白表示尚未记录，不表示工作已经发生。每次只需记下有意义的决定、问题和变化；证据应可定位到实际文件、提交、评审或匿名测试记录。

| 字段 | 填写内容 |

| 日期、本人、任务／Issue | 待填写 |

| 学习资源与实际掌握的能力 | 待填写 |
| 使用的 AI 或外部代码，以及本人如何核验 | 待填写 |

## 每周团队回顾

记录计划与实际完成情况、一次有效协作、一个具体问题、不同成员的看法、采取的调整，以及下轮检查该调整是否有效的方法。若引用 Tuckman，先描述事实，再解释为什么对应某个阶段；不要仅把团队贴上阶段标签。

## 设计决策条目

问题／证据 → 备选方案 → 决定与理由 → 代价和风险 → 验证方式 → 后续是否需要修改。需求改变时保留原记录并补充新的决定，不把所有过程改写成“一开始就知道答案”。

## 匿名任务测试条目

参与者代号、同意说明、测试版本、设备、任务、是否独立完成、卡点、观察、匿名原话、问题严重程度、对应修复及复测。不要保存无关真实身份、联系方式或私密聊天。
